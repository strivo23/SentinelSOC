# Evaluation dataset

`ground_truth.csv` has one row per synthetic scenario. A positive label means the scenario was intentionally generated to represent suspicious activity; it does not claim a real intrusion. `evaluation_predictions.csv` is generated by rerunning the actual detection engine over `sample_auth.log`; its scenario is marked detected when at least one emitted alert has the scenario's source IP. The evaluation page calculates its confusion matrix from these files. Run `python scripts/generate_sample_data.py` after changing synthetic data or rules to refresh them. This is a small demonstration set, not a representative benchmark.
