# Security policy

SentinelSOC is a local demonstration project and is not designed to be exposed as a production SOC service.

## Reporting a vulnerability

Please avoid filing public issues with exploitable details. Use GitHub's **Report a vulnerability** feature for this repository when available. Include the affected version, steps to reproduce, and potential impact. Do not include real authentication logs, credentials, or personal data in a report.

## Supported versions

Only the latest repository version is currently supported. There is no formal service-level response commitment.
